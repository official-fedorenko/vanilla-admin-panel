# Electro Tool Catalog

Переиспользуемый справочник **реальных моделей электроинструмента** (Bosch, DeWalt) по категориям. Задуман как независимый источник данных: папку можно скопировать в любой проект — она не зависит от остального кода.

## Содержимое

| Файл | Назначение |
|------|-----------|
| `tools.json` | сам каталог: категории → модели с характеристиками |
| `index.js` | Node-загрузчик с хелперами (`getByCategory`, `flatten`, …) |
| `images/` | SVG-иллюстрации по категориям (перфоратор, шуруповёрт, болгарка) |
| `README.md` | этот файл |

## Фото / изображения

Изображение задаётся на уровне **категории** (`image`) и автоматически подставляется каждой модели загрузчиком. У конкретной модели можно задать своё `image` — оно переопределит категорийное.

Сейчас это нейтральные **SVG-иллюстрации** (`images/*.svg`) — без копирайта, самодостаточные. Фирменные фото производителей (Bosch/DeWalt) сюда не кладём (авторские права); реальное фото конкретного экземпляра грузится прямо в карточке инструмента в приложении.

## Схема одной записи

```json
{
  "brand": "Bosch",
  "model": "GBH 2-26 DRE",
  "name": "Bosch GBH 2-26 DRE",
  "line": "Professional",
  "powerType": "corded",       // corded | cordless
  "powerW": 800,               // для сетевых (Вт)
  "voltageV": 18,              // для аккумуляторных (В)
  "brushless": true,           // бесщёточный двигатель (если есть)
  "impact": true,              // ударный режим (для шуруповёртов)
  "chuck": "SDS-plus",         // патрон / тип зажима
  "discMm": 125,               // диаметр диска (для болгарок)
  "image": "images/....svg"    // необязательно: переопределяет картинку категории
}
```

> ⚠️ Модели реальные и серийные. Числовые характеристики — **ориентировочные**: одна модель бывает в разных модификациях. Перед закупкой сверяйтесь с паспортом производителя.

## Использование (Node)

```js
const catalog = require('./data/tool-catalog');

catalog.getCategories();             // ['Перфоратор', 'Шуруповёрт', 'Углошлифовальная машина (болгарка)']
catalog.getByCategory('Перфоратор'); // все перфораторы (по имени категории или алиасу 'Болгарка' и т.п.)
catalog.getByBrand('DeWalt');        // все модели DeWalt
catalog.flatten();                   // плоский список всех моделей с полем category
```

## Как расширять

1. Добавляйте модели в нужную категорию в `tools.json` (соблюдайте схему выше).
2. Новую категорию заводите объектом с `category`, `slugEn`, `aliases`, `tools`.
3. Бампайте `schemaVersion` при изменении структуры (не при добавлении моделей).

Идеи на будущее: Makita, Milwaukee, Metabo, Hilti; категории — лобзик, дисковая пила, штроборез, сварочный аппарат.
